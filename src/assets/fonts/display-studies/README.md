# Display typography study fonts

이 폴더는 T3 Home cover의 display typography 비교용이다. 두 후보는 application
package 없이 공식 Google Fonts 원본을 self-host하며, 선택이 끝나면 미사용 family를
폴더 단위로 제거할 수 있다.
